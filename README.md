# TipFlow

A mobile-first fintech tipping platform prototype built with clean HTML, CSS, and JavaScript.

## What is included

- Instant localization toggle for English, Spanish, German, and French.
- QR-routed customer checkout preview with Stripe-style Apple Pay, Google Pay, and card entry.
- Worker dashboard with Company Mode, Independent Solo Mode, cash out, solo QR generation, and tax compliance.
- Manager dashboard for group tipping sections, worker assignment, real-time equal split calculations, and tax form downloads.

## Run locally

Open `index.html` in a browser or serve the folder with any static file server.
